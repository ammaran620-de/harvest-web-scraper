Source scope & runtime

Supported source: Books to Scrape, a public practice catalogue. Its prices and ratings are illustrative. Commands support a category, an inclusive maximum price, a minimum rating and a 1–5 page limit. Other websites require an extraction adapter. The hosted demo uses JavaScript; the downloadable Python/FastAPI version includes SQLite run history. No Gemini API is required.
